# Multi-Agent EDA Pipeline with CrewAI

An autonomous data analysis pipeline built with **CrewAI** that leverages specialized AI agents to process raw CSV data, compute statistics, detect anomalies, and generate a professional Exploratory Data Analysis (EDA) report in Markdown.

## Why this Architecture?

LLMs (even massive ones like Llama 3 70B or GPT-4) are notoriously bad at math and statistics. If you feed an LLM a raw CSV and ask for an analysis, it will frequently hallucinate numbers. 

To solve this, this pipeline **decouples the computations from the interpretation**:
1. **Computations (Deterministic):** Handled entirely by strict Python tools using `pandas` and `numpy`.
2. **Interpretation (Heuristic):** Handled by the LLMs reading the strict text outputs generated by the pandas tools.

By enforcing strict Pydantic `BaseTool` schemas and using a sequence of 5 specialized agents, this pipeline guarantees 100% mathematical accuracy while still delivering human-like business insights.

## The 5-Agent Architecture

1. **Data Ingestion Specialist:** Loads the CSV and generates a high-level profile (rows, columns, data types, missing percentages).
2. **Statistical Analyst:** Computes numerical summaries (mean, median, std, percentiles) and correlation matrices.
3. **Data Storyteller:** Translates the raw statistics into readable business interpretations and key findings.
4. **Data Quality Inspector:** Scans for anomalies, Z-score outliers, IQR violations, and placeholder strings.
5. **Technical Report Writer:** Compiles all previous findings into a final, beautifully formatted Markdown report.

## Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/multi-agent-eda.git
   cd multi-agent-eda
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Environment Variables:**
   Copy the example environment file and add your API keys:
   ```bash
   cp .env.example .env
   ```
   By default, the project is configured to use OpenAI's premium models (e.g. `gpt-4o`). 

## Running the Pipeline

Simply drop your dataset into the root directory (default is `retail_store_sales.csv`) and run:
```bash
python main.py
```
The final generated report will be saved inside the `outputs/` folder!

## Free-Tier & Local SLM Notes

If you are following the tutorial and wish to use **Groq's Free Tier**, there are a few adjustments you need to make to prevent rate limiting and schema rejection:
1. In `agents.py`, change the `DEFAULT_LLM` to `"groq/llama-3.3-70b-versatile"`.
2. In `agents.py`, uncomment the `litellm.drop_params = True` lines to prevent Groq from rejecting CrewAI's hidden cache parameters.
3. In `main.py`, uncomment `max_rpm=1` inside the `Crew()` instantiation to enforce a 60-second cooldown between agent tasks, ensuring you don't breach the tokens-per-minute limits.

*Note on Local SLMs (like Ollama phi3:mini or llama3.2:3b):* Small local models frequently struggle with strict JSON tool-calling and ReAct prompting. It is highly recommended to use a 70B+ model or GPT-4 class model for autonomous agentic workflows.
